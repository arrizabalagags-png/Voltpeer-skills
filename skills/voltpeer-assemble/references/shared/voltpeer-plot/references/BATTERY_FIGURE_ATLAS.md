# 电池图型小抄：先想清问题，再选画法

**快速选择：**常用数据图先走已有上传数据入口；CV、dQ/dV、GITT、电导率、XPS 分峰与 Raman 可选用 [六类明确输入的绘图脚本](SPECIALIST_RECIPES.md)。该页也区分了显微、同步辐射、模拟、安全测试与综述图的当前支持范围。热图、色标与普通坐标图拼在一起时，采用 [毫米布局与渲染后边界检查](PHYSICAL_LAYOUT.md)。

这份图谱用于电池综述和作者上传实验数据。它是广覆盖的选图小抄；新建定量面板时，以[逐 panel 核验的图型语法](BATTERY_FIGURE_GRAMMAR.md)和[来源记录](PANEL_EVIDENCE.json)决定实验协议、坐标与默认搭配。它不附带论文数值或原图；图型常见不等于其结论成立。先写“读者看完这张图应该知道什么”，再选下面的类型。

**图版审读范围：**本地 51 份论文 PDF 中，118 个已建立索引的主图页经过渲染与视觉查看；这不等于逐一检查每篇全部主文图、补充信息、原始数值或方法。28 个图页可提取部分矢量文字，另外 90 个图页的文字不能可靠自动测字号；可提取文字的页级字号中位数为 8.0 pt，但跨度可能包含标题或页眉，不能当作期刊规定。下面的排版数值是本项目的**出图验收建议**，投稿时仍以目标期刊当期要求和实际缩版预览为准。

## 投稿尺寸下先过这些版面关

1. 先选择目标期刊的[官方尺寸配置](JOURNAL_FIGURE_SPEC.json)，再以最终栏宽看导出的 PDF。以下旧版 8 pt 轴标题、7 pt 刻度、9–10 pt 字母只是宽松工作版建议，**不适用于 Nature 的 5–7 pt 正文字与 8 pt 小写粗体字母规范**；投稿时以具体期刊为准。不要照搬原图中难读的细字。
2. 约 90 mm 的单栏组合图，一行通常不超过两个独立坐标图；175–180 mm 双栏画布可尝试三列，再检查最窄绘图区。对齐的是**实际绘图区**、基线和同类轴，不只是外层图片框。
3. 面板字母可距绘图区左上约 1.5–2.5 mm，避开刻度、比例尺、图例、误差棒和曲线。同组间距一致，证据组之间留得更开；少用厚重边框。
   图内默认不加总标题、每格的解释性副标题、品牌名或页脚；它们通常属于图注、网页说明或来源台账。保留的条件/组别名必须确实帮助识别数据。
4. CE 与对称电池图保留完整循环或时间窗口；需要放大失效、波动或镀/剥细节时，做有范围标记、自己也能读懂刻度的 inset，避免遮住主曲线。
5. SEM/TEM 同组图片核对显示尺寸、比例尺位置和字号；堆叠谱图说明偏移与归一化；机理图用一致的颜色、线型和箭头含义。跨文献多面板图统一条件编码，并在图注保留各自来源与复用权利。

自动裁取论文 PDF 的图框可能只抓到一个子图，也可能带入正文；这类情况需要看整页。组合后的轴字、图例和比例尺要在**最终 PDF** 复核，位图/轮廓化文字不能仅凭字体提取程序判定。详细排版入口见 [拼版速查](../../../LAYOUT_RECIPES.md)。

**项目显示约定：**本项目新生成的逐圈容量、库伦效率、容量保持率及倍率/恢复阶段容量均用无连线散点；连续电压、光谱及连续 EIS 轨迹用无点实线。全电池循环采用同圈容量与 CE，并显示以明确参考圈、参考容量和同一测试条件计算的保持率；缺数据时先补材料，不补造面板。Li∥Cu 逐圈 CE 不强加保持率，Aurbach 按独立协议处理。拼版继承这些绘图规则；已有作者或论文原图保留其原始编码。这是本项目的显示约定，不是所有期刊的通用要求。

## 四种最常被混淆的电池结果

| 图 | 读者真正要判断的事 | 推荐画法 | 必须在图或图注交代 | 常见误导 |
| --- | --- | --- | --- | --- |
| **库伦效率 CE** | 在某个协议和条件下，容量回收比例怎样随圈数变化？ | cycle–CE 无连线散点；必要时旁边放选定圈的镀/剥电压–容量曲线。初始圈与平均值分开说明 | Li/Na/Zn 与 Cu/Al 等实际组合；CE 的分子/分母；电流密度、每圈面容量、截止规则、温度、平均区间、重复数 | 把 Li‖Cu 镀/剥 CE、全电池充放电 CE 和 Aurbach 平均 CE 混成一种；自动截掉 >100% 或失败点 |
| **全电池** | 正负极配对后，容量、能量或寿命在什么边界下成立？ | 同圈容量与 CE 散点主图，并给出明确参考的保持率散点；选定圈 voltage–capacity 为无点实线；倍率序列另图 | 电极组合、容量/能量分母、N/P、载量、Li 库存、E/C 或 E/S、倍率、电压窗、温度、coin/pouch、formation | 用半电池容量冒充全电池可实现容量；只报“高能量”而不说明电芯边界 |
| **半电池** | 工作电极相对哪种对/参比电极，在什么电位和容量基准下表现如何？ | 循环容量、rate、voltage–capacity、CV/LSV 按问题分别画 | 工作/对/参比电极的明确组合、参考电位、扫描速率或倍率、电压窗、载量和容量分母 | 把 Li‖Cu、Li‖Al、Li‖LFP 全叫“半电池”而不说各自测试目的 |
| **对称电池** | 两个同类电极在给定沉积/剥离协议下极化和失效如何变化？ | 带零线的 signed voltage–time 全程图；选定早/中/晚窗口放大；不同条件分面 | 两侧电极、极性、j (mA cm⁻²)、每半周期 Q (mAh cm⁻²)、压力、温度、总时长、失效规则 | 只截稳定片段；用“运行小时数”直接代表全电池寿命或正极兼容性 |

**自动画图状态：**上面四类中的逐圈 CE、全/半电池循环容量、对称电池电压有直接 Python 函数及 CSV/XLSX 入口，见 [上传数据说明](UPLOADED_DATA.md)。其余子图按下表的方法规划，并从原始数据或可编辑源文件制作。是否可直接比较还要让 `voltpeer-metrics` 检查具体化学体系。

## 其他实验图：用数据的原始含义选轴

| 类型 | 推荐显示 | 必留信息 / 容易画错的地方 |
| --- | --- | --- |
| 电压–容量曲线 | voltage (V) 对 specific/areal capacity；充放电用线型或方向分别编码，所选圈数直标 | 容量分母、电压参考、倍率、循环号。不能把不同容量归一化后又标绝对单位 |
| 倍率性能 | 按测试顺序画 step–capacity，并保留恢复步骤 | 1 C 的定义、各步圈数、容量单位、重复数；不要把恢复步骤移到前面 |
| EIS Nyquist | Re(Z) 对 −Im(Z)，同一状态下共轴或分面 | 频率范围、SOC、温度、交流扰动、拟合模型/残差；不要从半圆外观直接断言某个具体界面电阻 |
| CV / LSV | 电位相对指定参比电极对电流/电流密度；正反向扫线分明 | 扫描速率、工作/对/参比电极、电压起点和终点。LSV 起始电流不等于长期循环稳定窗口 |
| GITT / PITT | 电位–时间原始阶跃与推导的扩散系数分面 | 脉冲/静置时长、温度、计算模型、SOC、面积和厚度；不要把模型输出当直接测量 |
| dQ/dV | 微分容量–电位，原曲线和处理后的导数成对保存 | 导数算法、窗口与平滑参数。峰位移动不能脱离电压校准解释 |
| Ragone / 能量密度 | energy vs power，附计算边界和测得/推算状态 | 质量/体积分母、活性物/全电芯、平均工作电压、极耳和包装是否计入；不同边界不得直接排名 |
| 失效与安全 | 温度/压力/热流/气体等对时间或温度，多条件分面 | 触发条件、样品量、SOC、升温速率和防护边界；不以单项测试宣称整体安全 |

## 稀释剂与电解液机理图

把“设计假设 → 溶剂化证据 → 界面证据 → 电池验证”当成一种**证据顺序**，不是默认的因果证明。每个面板用角标或标题区分：`measured`（实测）、`calculated`（计算）、`schematic`（示意）、`hypothesis`（待验证）。

| 材料 | 通常画什么 | 核对要点 |
| --- | --- | --- |
| 配方/溶剂化示意 | 盐–溶剂–稀释剂和第一溶剂化鞘层；箭头标“提出/支持/观察” | 真实分子结构、浓度定义、原子颜色、离子电荷；示意不能替代配位数测量 |
| Raman / FTIR / NMR | 原始谱与必要的峰归属；多样品按同一坐标排列 | 波数 cm⁻¹、化学位移 ppm、基线处理、归一化、峰拟合和引用 |
| RDF / 配位数 / MD | g(r)–r 与积分配位数并列；快照单独标“simulation” | 力场、模拟时间/组分、r 的单位、计算方法；一个快照不等于总体分布 |
| DFT / ESP / 结合能 | 一致色标的电势图、能量比较点图或能级图 | 计算水平、体系大小、能量参考和单位；颜色条范围不能各图不同还作直观比较 |
| 电导率 / 黏度 / 迁移数 | 属性对浓度或温度，多尺度时分面 | 测量方法、温度、电解液配方、统计误差；不只展示最优点 |
| 界面 XPS / ToF-SIMS | 离子化学图、叠加图与溅射时间剖面，按样品状态排列；原始质量谱/峰归属可独立成图 | 离子极性、精确碎片归属、取样/清洗、像素标定、信号单位及归一化、溅射束与时间；没有独立坑深校准就不把时间写成 nm，不把不同离子强度当绝对组成 |
| SEM / TEM / AFM / cryo 图像 | 原始图像加比例尺；条件一致的对照成组 | 比例尺、加速电压/成像模式、取样圈数、位置与对比度处理；不跨样本粘贴区域 |
| XRD / 原位图 | 强度–2θ 或时间/状态热图 | 辐射源、背景扣除、峰索引和色标；热图显示的状态与电化学时间轴要对齐 |

## 常见版式：什么时候该用

| 形式 | 可用场景 | 画之前先核实 |
| --- | --- | --- |
| 分组柱图 / 点图 | 少量同单位、同测试边界的样品比较 | 从零起点或清楚说明截断；重复数、误差棒意义；多组时点图通常更易读 |
| 堆叠柱图 | 组成部分确实能相加到一个有定义的总量 | 每部分同分母，合计规则明确；不把不同测量方法的比例硬凑到 100% |
| 折线趋势图 | 连续时间信号；离散温度或逐圈结果另用观察点 | 横轴是真实顺序；数据缺口和失效点不能用平滑线填过 |
| 雷达图 | 少数同向、可归一化的设计权衡指标 | 每根轴的归一化公式、方向、上限清楚；主要数值最好另附表或点图 |
| 三维球体/分子示意 | 有坐标或结构模型，想解释构型 | 透视、颜色和尺寸只作示意时应写明；不能用漂亮的球体替代 RDF、配位数或结构证据 |
| 圆形综述图 | 主题存在循环、层次或互补关系 | 扇区面积若不代表数量，必须明确；文字应在投稿尺寸仍可读 |
| 多面板拼图 | 不同证据共同支持一项结论 | 面板职责不同，比较图的实际绘图区对齐；概念图和实测图的证据类型可辨 |

## 统一风格与拼图

颜色先表示**对象身份或证据角色**，不要在不同面板里让同一颜色反复变义。优先用 [共享主题](../assets/figure_theme.json)，再配线型、符号和直标。比较图统一坐标范围和实际绘图区；拼版时以毫米定宽、明确行高和面板标签带。扫描空白边并不等于自动裁剪；任何裁剪都要说明原因并确认没有截掉比例尺、轴、误差棒或异常点。最终用 [拼图技能](https://github.com/arrizabalagags-png/Voltpeer-skills/blob/79b4238a5a7dfc963bafc0aefacd2337f9795ba8/skills/battery-figure-assemble/SKILL.md) 导出 PDF、PNG、逐面板检查图与对齐叠加图。

这张图谱是**选择方法**，不是“给一张截图就能还原它的数据”的承诺。作者只有图片没有原始数据时，先找实验文件或文献源数据；数字化读取须单列方法与不确定性，不能冒充原始测量。

已经知道要画哪一类时，直接看 [十类展示级图件的布局配方](SHOWCASE_RECIPES.md)，按该图型安排主次、字母、直标、留白和源数据。导出 SVG 后若只需手工改字、线、间距或拼图位置，按 [Inkscape 小白微调指南](SVG_HANDOFF.md) 操作。

## 文献里可复用的画法

下面只提炼图的**组织方法与测试边界**，不复制论文图或数值。初版图谱建立时，对提供的 51 份稀释剂相关 PDF 做了全文和主文图注索引；其中 11 篇做了扩展图型案例核查。其余论文在图注索引层，不能称为逐图视觉核验。图号按论文主文，实际重画前仍须看原 PDF 图页和方法。

| 论文中的面板 | 可借鉴的做法 | 本 skill 的规则 |
| --- | --- | --- |
| [Huang et al., *Adv. Funct. Mater.* 2022, Fig. 5](https://doi.org/10.1002/adfm.202211364) | 同一研究把不同电流/面容量的 Li‖Cu CE、Aurbach 类 CE 与 Li‖Li 测试分别展示 | CE 协议、分子/分母和每圈面积容量先核对，再决定共轴还是分面 |
| [Liu et al., *Small* 2024, Fig. 4](https://doi.org/10.1002/smll.202311812) | 全电池循环与选定圈充放电曲线相邻，且有正极面容量、锂厚度和 N/P 边界 | 图注和条件台账保留这些边界，避免把标签“全电池”当作实用性证明 |
| [Zheng et al., *ACS Energy Lett.* 2018, Fig. 3](https://doi.org/10.1021/acsenergylett.7b01213) | 对称电池同时给长时主图和不同时段放大轨迹 | 放大窗应能回指主图，不能只挑稳定时间段 |
| [Zeng et al., *ACS Nano* 2024, Figs. 1 and 4](https://doi.org/10.1021/acsnano.3c07038) | 光谱/模拟证据与多种 CE、界面/电芯测试形成不同层次 | `measured`、`calculated`、`schematic` 分开标；Aurbach 与逐圈 CE 不合并为同一指标 |
| [Hu et al., *Adv. Mater.* 2024, Figs. 1 and 5](https://doi.org/10.1002/adma.202312161) | 低温金属沉积/剥离与无负极电池结果属于不同测试边界 | 按温度、协议和电芯构型分面；温度必须与电流/倍率一同标清 |
| [Yu et al., *ACS Energy Lett.* 2018, Fig. 7](https://doi.org/10.1021/acsenergylett.8b00935) | 分别改变载量、电解液量和锂厚度来检验表现边界 | 跨论文基准图不能只按电解液配方排名；把会改变结论的测试条件显式分层 |
