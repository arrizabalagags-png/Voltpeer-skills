# Review takeover and parallel editing

Use this when continuing another session's draft, reconciling edits from a second model, or preparing several manuscript files together. Use project conventions when they already record the same decisions.

## Freeze the input and divide the work

Read the current files and recent receipts. Record which manuscript, supplements, responses, and figure masters are authoritative for this task. Date, hash, or version the set as appropriate. Record where the author's latest decisions supersede older drafts, especially exact wording, figure selection, and permitted scope. Keep a read-only baseline and work on a separate candidate. Send the collaborating editor only the materials its task needs, within the user's authorized service and disclosure scope.

Assign one integrator. A language editor proposes changes against stable locations and supplies reasons for changes of meaning. An evidence checker consults the underlying source, data, or revision request. The integrator accepts, corrects, or leaves each consequential proposal open. If working alone, run the evidence and wording passes separately. A model's agreement records a second opinion and each acceptance still needs a source or author decision.

For long document work, begin with a small section and confirm that paragraph IDs, fields, facts, and export behavior survive the merge. Use semantic batches for the remaining passages. Ask the editor to return location, proposed text, and any changed fact or qualifier. Preserve completed candidates after a timeout or validation error. Identify the first missing location and check whether a title, caption, or table has been mistaken for body prose. Resume the remaining material against the same baseline and use the final inventory to catch omissions and duplicates.

## Record decisions and read the delivery

Keep a compact record of version, stable location, proposal, evidence checked, decision, and the final text location. Use statuses such as proposed, accepted, corrected, retained, and pending. Separate evidence state from editing state. Access to a model, a submitted prompt, and a returned review are distinct milestones. Report independent review only when a suitably isolated reviewer returned a report for the frozen set.

Synchronize the revised claim wherever it is repeated. Check the affected manuscript passages, abstract, conclusion, captions, figures, SI, and reviewer excerpts as relevant. Read the export the author will open. Check actual embeds, data and units at a sample of changed locations, and full coverage of the affected section or review points. Let unresolved evidence, permissions, and possible further edits travel with the handoff. [Session handoff template](../assets/templates/SESSION_HANDOFF.md).

## Rehearsal with invented inputs

A second editor returns nine of ten body paragraphs and stops on a short table continuation title. The ninth completed suggestion upgrades a tentative impedance interpretation to a proven transport mechanism. Retain the nine proposed paragraphs, move the table title out of the body-edit batch, resume the one missing paragraph, and correct the upgrade against the evidence. Recount the body and inspect the table and changed wording in the export.
