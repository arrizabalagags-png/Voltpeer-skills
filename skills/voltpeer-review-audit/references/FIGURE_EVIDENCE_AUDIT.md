# Figure evidence audit

Use this for a review figure that combines literature panels, reconstructed data, or a drawn mechanism. Preserve the last author-approved art and its source set before proposing changes. A layout correction can start from a copy of the approved source panels. Record which modifications affect typography or placement and which alter the scientific representation.

## Review the panel and its provenance

- For each reused panel, locate its reference, DOI or stable URL, original panel, original image, changes made, and license or permission evidence. Check rights per source and per reuse type, especially in mixed-source composites. A credit line and a rights receipt answer different questions.
- For numeric panels, identify raw data, author-provided tables, calculations, simulations, or digitization from a rendered figure. Check units, branch, axes, legend, points, tick labels, and scale markers against that source. For digitization, keep the original layer and mark the method and precision limit. When the original data are unavailable, say which cross-check used only a rendering.
- For an evidence collage, preserve the active crop, source aspect ratio, scale bars, color bars, inscriptions, high- and low-magnification pairs, and native curves. If a change is deliberate and justified, log it per panel. Equal layout dimensions are a visual choice and each study keeps its own metric and scale.
- For a mechanism figure, trace the direction, start and end of each arrow against the physical pathways and process phase. Check material labels, boundaries and the relation between overview and zoomed detail. Tie each demonstrated feature to a source and label hypothetical elements in the illustration or caption.
- For a synthesis chart, check the calculation, inclusion rules, case count, denominator and category overlap. When conditions prevent a score or ranking, report source-specific observations or limit the comparison to a comparable subset.

## Inspect the delivered file

Check the actual embed in the manuscript and final-size PDF or image. Compare panel contents, axes and labels against the source when the layout changes. Inspect scale, line width, contrast, crop and caption placement at the intended print or screen size. Distinguish editable outer labels and shapes from raster or outlined source content inside vector containers. A hash can establish that source files stayed stable. Render comparison and source inspection address geometry, labels, and scientific meaning.

Document the audit's coverage and open items. Where a panel fails a scientific check, show the issue before making a cosmetic fix. Where the author's current tool choice excludes a graphics workflow, deliver findings or apply a targeted change using the authorized tools.

## Invented audit examples

- A microscopy panel fills a new rectangular cell by vertical stretching. Compare its shape against the source, restore the original geometry, adjust the available space, and check the scale bar at final size.
- A source chart is available only as a bitmap. A digitized trace can be identified as a reconstruction with stated precision. The source panel can also be placed as a preserved raster with separate editable labels.
- A mixed-source composite has one work with a verified open license and another with a pending permission request. Record panel-level states and retain the second item as open in the package record.
